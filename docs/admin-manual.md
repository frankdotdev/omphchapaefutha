# Admin manual

Sign in at `/admin`. You see only the sections your role allows.

## Everyday tasks
- **Announcements / Events**: Add, set the Lagos publish time, set status to Published. Draft and Archived items are never public.
- **Schedule changes**: Use for one-day changes. *Cancel* or *Reschedule* names the regular activity; *Add* creates a special one. The regular timetable is untouched.
- **Home slideshow**: Add a Latin text, its English translation and source. Optionally choose a framed image and/or a background image from Media. Slides you add replace the built-in set after the first slide; delete or archive them all to return to the defaults.
- **Mass intentions**: Payment check -> confirm payment -> Awaiting approval -> choose date and Mass -> Approve. Approved intentions appear publicly for their date. Use *Daily sheet* to print a day's list. Hand-entered intentions need a recorded reason.
- **Prayer requests**: Only requests where the person agreed to publication can be published. Contact details are never public.
- **Media**: Upload JPEG/PNG/WebP up to 5 MB with a description and the source/permission. Images under 1200 px wide look soft as full-width backgrounds.
- **Settings**: Address, phone, email, map link, the chaplaincy history (shown on About) and offering instructions. All public, and changes show within minutes.
- **Feast days (local)**: For a celebration the Church's calendar does not carry (a Nigerian or Abakaliki feast, the chaplaincy's patronal feast, a special day). Give the date, tick *Repeats every year* if it recurs, choose the rank and colour, and choose *Also today* or *Main celebration of the day* (which overrides the day's headline and colour). Set Published.
- **Daily readings**: To enter the readings for any day by hand (including a local feast), add the date, the references, and the source and permission note. Set Published; it replaces the link-out for that day.

## Notes
- Deleting is permanent; set status to Archived to hide something instead.
- Every change is recorded in the audit log (who, when, which fields).
- Names of Church office-holders must be checked against official sources and marked Verified before publishing.
